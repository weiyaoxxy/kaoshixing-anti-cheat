# sharingType

A Boolean value that indicates the level of access other processes have to the window’s content.

```
var sharingType: NSWindow.SharingType { get set }
```

## Discussion

The value of this property represents the sharing level of the window’s content. See [`NSWindow.SharingType`](/documentation/AppKit/NSWindow/SharingType-swift.enum) for possible values.
