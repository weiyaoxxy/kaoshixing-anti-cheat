68:  first, a blit synchronizations must be completed (see synchronize methods of MTLBlitCommandEncoder).
69:  Blit overhead is only incurred if GPU has modified the resource.
70:  This is the default storage mode for OS X Textures.
71: 
72:  @constant MTLStorageModePrivate
